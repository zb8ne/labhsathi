# Domains this project's `source_url` fields are allowed to point at.
#
# This is the actual, complete list of domains present in
# services/labhsathi-core/data/schemes.json today -- not every .gov.in/.nic.in
# domain that exists, and deliberately not a wildcard match on those TLDs,
# because several legitimate schemes here point at real government-affiliated
# bodies that aren't under those TLDs at all (licindia.in, pfrda.org.in,
# www.mudra.org.in, www.standupmitra.in, and a few more below).
#
# The point of a fixed, committed list rather than a wildcard: a future
# schemes.json edit that introduces a typosquatted or otherwise wrong domain
# (e.g. a look-alike for pmkisan.gov.in) fails this check by simply not being
# on this list, and a human has to deliberately add it here -- which is a much
# stronger guard than "matches *.gov.in", since a convincing fraud domain
# could easily also end in .gov.in-looking text without being real.
#
# Adding a new domain here should only happen after manually confirming it's
# the scheme's real, official source -- see scripts/verify-source-links.sh.
